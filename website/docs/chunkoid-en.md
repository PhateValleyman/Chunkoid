## Chunkoid v2.0.0 is Now Available

The ultimate Minecraft world converter built specifically for Android. 100% Free and Open Source — No PC Required!

---

### 🌟 Converter Suite - Core & New Features

- **Brand New Modern UI & Dynamic Theming (v2.0.0 New)**: Completely revamped interactive UI with dynamic palette engine (Material You), tailored for all notch and full-screen Android displays.
- **Low RAM Anti-Crash Mode (v2.0.0 New)**: Deeply optimized for devices with 4GB~6GB RAM to prevent Out-Of-Memory (OOM) crashes on large worlds.
- **Background Wake Lock (v2.0.0 New)**: Enables unattended background conversions without fear of being killed by Android aggressive power-saving policies.
- **Entity Loss Warnings & Alerts (v2.0.0 New)**: Intelligently inspects cross-edition and cross-version entities before conversion, displaying detailed notices for safe data handling.
- **Dimension Pruning Customization (v2.0.0 New)**: Selectively convert or omit Overworld, Nether, or The End to save massive conversion time and disk space.
- **Bidirectional JE-BE & Version Upgrades**: Converts between Java Edition (JE) and Bedrock Edition (BE) seamlessly with fine-grained version mappings.
- **Resource Pack Converter**: Cross-converts textures and models between Java and Bedrock resource packs.
- **NetEase Encrypted World Decryptor**: Built-in decryption toolkit to unlock and convert encrypted worlds with one tap.
- **Full Whitebox Logs**: Real-time console logs displaying each kernel step clearly for easy troubleshooting.
- **Unified Output Manager**: Export as `.mcworld`, `.zip`, or directory formats, and easily import into your Minecraft game.

- **Language**: Kotlin / Java

- **Architecture**: MVVM
- **Runtime Core**: Chunker-cli, OpenJDK Runtime (Termux Env)
