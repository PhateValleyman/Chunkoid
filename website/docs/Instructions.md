## Chunkoid 软件操作手册

---

### 1. 世界转换器基本操作

1. **选择存档**：打开应用后点击首页的【选择世界】按钮，支持直接选取 `.zip` 压缩包、`.mcworld` 基岩版文件或已解压的世界文件夹。
2. **自动扫描包体**：软件内置世界识别系统（WSS），会自动检测嵌套目录中的关键世界层级（`level.dat` / `db` / `region`），无需用户反复手动解压提取。
3. **配置转换参数**：
   - 选择目标平台（Java 版 JE 或 基岩版 BE）。
   - 选择目标版本号（例如 1.20.x、1.21.x 等）。
   - 如需按需节约体积，可在转换选项中配置【维度裁剪】（主世界 / 下界 / 末地）。
4. **开始转换**：确认配置无误后点击【开始转换】。如果涉及实体跨端转换，系统会弹出【实体预警提示】，确认后即开始全流程白箱转换。
5. **管理与导出**：转换完成后，前往【输出管理器】可一键解压、打包导出或直接导入 Minecraft。

---

### 2. 核心设置与高级优化项

- **防闪退模式 (Low RAM Mode)**：开启后会对内存占用和垃圾回收进行低运存调优，大幅减少 4GB~6GB 手机在转换大世界时的闪退概率。
- **后台唤醒锁 (Wake Lock)**：开启后转换过程中会持有 CPU 唤醒锁，保障息屏或切到后台时转换进程不被安卓系统强制中断。
- **JVM 最大内存分配**：可根据手机空闲运行内存手动调节 Java 虚拟机最大分配值（建议设为可用内存的 60% 左右）。
- **保留原始 NBT**：保留未受转换规则影响的原始 NBT 标签（在跨版本且格式兼容时生效）。
- **动态取色与外观**：支持跟随系统壁纸或自定义主题动态取色，打造沉浸式 Minecraft 质感。
- **日志导出功能**：遇到异常时可开启日志记录，方便一键导出日志并发送至官方交流群反馈排查。

---

### 3. 拓展工具箱使用

- **材质包转换器**：选择 JE 或 BE 资源包 zip 文件，一键转换贴图结构与 `manifest.json` 配置。
- **网易存档解密器**：一键导入网易版加密世界存档，快速解密提取为标准世界格式后再行转换。
- **终端控制台 (Terminal)**：提供直通 Chunker-cli 底层内核的环境，供高级进阶用户输入自定义参数命令。
